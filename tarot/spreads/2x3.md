# Расклад 2x3

```
[1] [2] [3]
[4] [5] [6]
```
Два ряда по три карты, три столбца.

## Правила
- Позиции важны. Верхний ряд «над» нижним (см. правило верхней карты в CLAUDE.md).
- Соседи по горизонтали: 1–2, 2–3, 4–5, 5–6. По вертикали (столбцы): 1–4, 2–5, 3–6.
- Взгляды между соседями проверяем в каждой паре; смотрят за край расклада = выход из ситуации.

## Смысл позиций
Фиксированных значений нет, Рони задаёт их по ситуации перед раскладом:
- чаще всего **6 карт на один вопрос** без значений позиций: читаем как единую картину через взгляды и соседство;
- иногда **ряды получают значение** (например, верхний ряд = «сейчас», нижний = «потом»); тогда Рони говорит об этом в вводе. Если значения не названы, не придумывать, а читать как «6 карт на один вопрос».
